# 00 — ERGO Project Bindings

## Purpose
Bind CSC SOP, project doctrine, code doctrine, and the active Ergo-Light engine doctrine into one local authority surface.

## Active authority stack for Ergo-Light
1. Project doctrine and synthesis documents in `spec/` and `reports/`
2. CSC SOP set in `docs/csc_sop/`
3. Local runtime/spec/state surfaces in `runtime/`, `data/`, `state/`, and `continuity/`

## Strict rule from this adoption point forward
- strict adherence to SOP is mandatory
- strict adherence to project doctrine is mandatory
- strict adherence to code doctrine and standards is mandatory
- CSC gate/finalizer surfaces are part of normal project operation, not optional extras
