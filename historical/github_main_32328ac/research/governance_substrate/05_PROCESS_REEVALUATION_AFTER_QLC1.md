# Process Re-evaluation after QLC1

## What the process taught that was not explicit at campaign start

1. **The enforcement problem is recursive.** Once we distinguish observed compliance from endogenous enforcement, the governance layer itself becomes subject to that distinction. Library functions and tests are scaffolding until an ordinary consequence boundary invokes them. This is not implementation polish; it changes the evidence class of the entire governance claim.

2. **Qualification is better modeled as a lifecycle edge graph than a status field.** Requalification debt, query-relative admission, campaign reauthorization, negative evidence, and doctrine challenge all describe transitions/relations among evidence, authority, question, and consequence. A monolithic QUALIFIED flag loses causal structure.

3. **Doctrine must be challengeable to remain doctrine rather than dogma.** Enforcement and learning are not opposing requirements if credible contradiction opens a governed challenge that blocks silent promotion but preserves evidence.

4. **Research OS compliance has the same effect-truth problem as scheduler effects.** A populated receipt is annotation. Even the new process_effect check only witnesses non-empty discriminative structure; it does not prove the machinery causally improved the decision. The stronger future test is counterfactual/process-delta evidence: what rival was killed, branch selected, or conclusion changed because the machinery ran?

5. **Continuity should carry debt and negative space, not just current state.** A 1:1 fresh thread needs to know not only the frontier, but which conclusions need requalification, which paths were killed, and exactly what would reopen them. Otherwise it reconstructs state but loses the shape of the search space.

6. **Closure escape and bounded research depth compose.** Repeated unresolved discriminators inside one primitive closure increase justification for broader search, while reserve/consequence controls how much search is affordable. Neither authorizes a new primitive or method waiver.

7. **The sharpest next embodiment point is not every tool call.** Fresh rehydration/checkpoint seal is the best first ordinary-path boundary because it directly attacks the user's highest lived friction and the 1:1 thread-transition requirement while remaining non-mutating/readiness-oriented. Promotion is the second boundary.

## New candidate laws
- LIBRARY AVAILABILITY != ENDOGENOUS ENFORCEMENT.
- QUALIFICATION IS A RELATION/LIFECYCLE, NOT AN INTRINSIC PROPERTY OF EVIDENCE.
- DOCTRINE ENFORCEMENT WITHOUT A CHALLENGE PATH DEGENERATES INTO DOGMA.
- PROCESS ANNOTATION != PROCESS EFFECT; PROCESS EFFECT SHOULD EVENTUALLY CARRY A DISCRIMINATIVE DELTA.
- CONTINUITY WITHOUT REQUALIFICATION DEBT + NEGATIVE EVIDENCE IS STATE RECOVERY, NOT SEARCH-SPACE RECOVERY.
