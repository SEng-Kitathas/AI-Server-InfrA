## Centralization constraint
Do NOT create a GovernanceManager owning these states. Candidate shared substrate contains pure/non-authoritative relations and witnesses only:
- BindingWitness: identity/epoch/session/currentness comparisons.
- AdmissionWitness: query/scope/consequence relation.
- QualificationDebt: changed load-bearing bindings -> debt.
- EvidenceClass: server-enforced/projected/client/thread/manual.
- ScarRecord: killed claim + attack + scope + reopen condition.
- TransitionWitness: previous + semantic delta -> current consistency.
- ProcessEffectWitness: rival/branch/conclusion deltas caused by research machinery.

Authoritative owners remain: mutation authority, protocol/doctrine, RES, UCM, artifact registry, Git, scheduler effect profile, project registry, recovery supervisor.

## Sharpest anti-monolith discriminator
If the shared substrate is removed, owners must retain their authoritative state and merely lose cross-plane qualification assistance. If shared substrate can mutate owner state or manufacture READY/authority by itself, design FAILS.
