# Historical Material

Everything under `historical/` is preserved as historical/reference evidence, not as the active server baseline.

Historical files are intentionally retained byte-for-byte where possible. Original trailing whitespace, EOF shape, obsolete conventions, and other historical defects may therefore remain. Do not normalize those files merely to satisfy active-tree style checks.

`HISTORICAL PRESERVATION != ACTIVE STYLE AUTHORITY`
`BYTE-FIDELITY != CURRENTNESS`
