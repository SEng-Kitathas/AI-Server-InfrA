# PCMMAD Browser Bridge



The browser bridge is optional. Start it only when browser automation is needed.



## Start



Double-click:



```text

START_BROWSER_BRIDGE.cmd

```



It starts:



```text

http://127.0.0.1:4471

```



## Check



Double-click:



```text

CHECK_BROWSER_BRIDGE.cmd

```



## Stop



Double-click:



```text

STOP_BROWSER_BRIDGE.cmd

```



The bridge requires Python dependencies used by `browser_bridge_service.py`, including Flask and Playwright.
