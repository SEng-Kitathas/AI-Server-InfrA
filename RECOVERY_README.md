# PCMMAD V29 recovery baseline

This package is a clean derivative of the surviving receiver evidence and the verified V28 parity anchor. It is not a copy of the lost Windows machine state.

Do not restore archived `.venv`, bytecode, local key files, old ngrok URLs, or historical absolute-path assumptions. Use the package setup and launcher scripts to reconstruct machine state.

The V29 package adds the native protocol plane while preserving the compact 30-operation schema and the established route/tool architecture.
