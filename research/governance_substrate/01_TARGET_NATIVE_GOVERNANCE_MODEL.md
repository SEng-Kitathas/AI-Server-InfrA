# Target-Native Governance Model v0

## Primitive claim
Do not create a new governance authority. Governance is a verifier/admission layer over existing authoritative owners.

Each governed claim is a relation:

`subject + question -> authoritative_owner + currentness_witness + admission_rule + projections`

The kernel may report contradictions and block promotion where an existing authority contract says it may; it cannot mint truth, project intent, mutation permission, scientific canon, or user identity.

## Seven consistency relations
1. AUTHORITY: exactly one authoritative owner for a consequential question.
2. CURRENTNESS: authority has an explicit usable-now witness where time/state matters.
3. PROJECTION: derived/agent/HUD surfaces name their source and may not outrank it.
4. ADMISSION: candidate evidence does not become doctrine/canon/current state without the owning promotion gate.
5. EXECUTION: submitted/started/completed/registered/promoted remain distinct states.
6. RECOVERY: derived state has a reconstruction source and corruption cannot mutate authority.
7. RETIREMENT: compatibility projections have a measurable removal condition.

## Composition law
Existing PCMMAD mechanisms remain owners: artifact registry, mutation authority, effect witnesses, migration framework, UCM/ICF/RES, global doctrine, supervisor, HUD. The governance kernel only evaluates declared relations among them.

## Anti-manager constraint
No global semantic registry, planner, policy oracle, or universal state machine is admitted merely to implement governance. A new primitive requires a contradiction that cannot be expressed/checked by composition of existing owner contracts.
