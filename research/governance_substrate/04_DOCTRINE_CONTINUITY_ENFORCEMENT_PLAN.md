# Doctrine / Context / Continuity Governance — Candidate Enforcement Plane

Status: LOCAL EXPERIMENT. Governance remains authority NONE.

## Highest-lived-friction target
Enforce consistency among doctrine, fresh-instance ingress, bounded context, continuity artifacts, RES/UCM applicability, protocol mode, and research-process requirements without allowing governance to author doctrine or continuity.

## Existing owners remain sovereign
- Global doctrine: versioned global_doctrine current/history + explicit promotion.
- Universal invariants/SOP: existing doctrine.invariants and SOP guard/ingestion owners.
- Project intent/current continuity: ICF-CS + project continuity artifacts/protocol ledger.
- Context: context_engine/project.context.rehydrate is bounded retrieval/projection, never authority.
- RES: canonical research epistemic snapshot/readiness owner.
- UCM: authoritative user-continuity ledger/head; retrieval remains navigation, not project authority.
- Research methodology: Research OS doctrine; governance may require evidence of additive use for non-trivial work but may not invent research conclusions.

## Candidate enforced relations
DCE1 Doctrine projection: fresh ingress must identify current doctrine/invariant source+digest; stale/missing -> NOT_READY/UNKNOWN, never silently use remembered doctrine.
DCE2 Continuity pair: Live Shadow and DTS are projections with explicit currentness/lineage witnesses; disagreement is surfaced, never smoothed.
DCE3 ICF ingress: project mirror/runtime carrier source and before/after witness remain bound; no silent migration.
DCE4 Context packet: every selected item retains source/path/class and authority role; context relevance != authority.
DCE5 RES applicability: non-trivial research state cannot be treated as current when RES readiness/materiality says otherwise.
DCE6 UCM applicability: UCM facts/decisions may condition collaboration but cannot override project doctrine/current state/tool authority.
DCE7 Research-process additive gate: non-trivial problem must carry a compact process receipt showing Loop+ topology, OARR attack(s), CSC audit, Attention Reservoir breadth check, HELIX next discriminator or explicit lawful stop. Missing receipt -> PROCESS_UNQUALIFIED, not automatic task failure for trivial work.
DCE8 Research machinery additive: specialized methods do not replace Research OS; they attach beneath it.
DCE9 Rehydration consequence: fresh-session readiness requires doctrine + continuity + applicable RES/UCM + bounded context currentness together, with UNKNOWN preserved.
DCE10 Governance itself: enforcement result has authority NONE; it can gate readiness/promotion only where an existing owner explicitly delegates that gate.

## Non-triviality
Do not use a brittle token/length threshold. Candidate classification is consequence-based: architectural/design choice, research claim, mutation plan, migration, promotion, cross-plane inference, persistent state change, or multi-step diagnostic with competing hypotheses => non-trivial. Ambiguous => treat as non-trivial for process qualification, while allowing the operator to explicitly classify trivial.
