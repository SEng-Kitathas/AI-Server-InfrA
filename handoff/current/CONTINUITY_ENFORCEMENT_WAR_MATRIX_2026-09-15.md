# CONTINUITY ENFORCEMENT WAR MATRIX — 2026-09-15

## Commander direction
Every continuity/context/Commander Intent/shadow surface must be operationally enforced: kept current AND surfaced/used where it has the highest decision value. Enforcement must not become ritual rereading, context flooding, or checklist theater.

## Root distinctions
- `SURFACE CURRENT != SURFACE USED WHEN NEEDED`
- `SURFACE ENFORCED != SURFACE RITUALLY RECITED`
- `MORE CONTEXT != BETTER CONTEXT`
- `HANDOFF PACKET EXISTS != NEXT THREAD REHYDRATES CORRECTLY`
- `PERSISTED != RETRIEVED AT THE DECISION POINT`
- `THREAD FULL != PERMISSION TO LOSE COMMANDER INTENT`

## Required mechanisms
1. Surface registry: identity, authority, subject, update triggers, stale conditions, relevance triggers, surfacing priority, reopen conditions.
2. Change routing: load-bearing state change -> exact surfaces requiring refresh; no blind touch-all mutation.
3. Intelligent surfacing: smallest authoritative relevant slice, ranked by current task/risk/seam; low-value surfaces remain stored.
4. Handoff gate: cannot declare thread/campaign handoff complete while required active surfaces are stale, Commander Intent coverage is incomplete, active mutation/evidence handles are missing, or contradictions remain unmarked.
5. Rehydrate gate: new thread verifies handoff package, surfaces, exact HEAD/runtime identities, blockers, active campaign, latest green/failure evidence, and commander deltas before mutation.
6. Drift detector: intent/functionality claimed in one active surface but absent/conflicting elsewhere becomes an explicit deficit.
7. Usage receipts: important continuity surfacing should record which authoritative surface informed which decision without turning every read into biography noise.

## Hostile matrix
- one required surface stale while hashes of others are current;
- Commander Intent current but not surfaced during directly relevant mutation;
- irrelevant huge continuity corpus floods context and displaces current evidence;
- contradictory Current State vs Live Shadow vs Commander Intent;
- handoff during uncommitted mutation;
- thread dies before handoff generation;
- duplicate/old handoff races new generation;
- corrupted pointer/generation;
- operator changes intent late in thread;
- forgotten revisit item becomes current blocker;
- new Agent starts from stale live-runtime snapshot;
- continuity engine unavailable because Receiver is down;
- Daemon down but project-control continuity survives;
- low-value historical scar incorrectly blocks unrelated work;
- ritual touch-all changes timestamps/hashes without semantic update.
