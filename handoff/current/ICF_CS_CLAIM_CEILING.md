# ICF-CS v1.2 — Claim Ceiling

ICF-CS v1.2 does not claim:
- that presence of RES proves research truth;
- that RES synthesis is doctrine;
- that presence of UCM proves user/project/runtime truth;
- that UCM user preference grants tool or project authority;
- that hydration equals consumption or decision use;
- that semantic retrieval equals evidentiary support;
- that a user-session mode label can override contradictory runtime/project evidence;
- that all projects require identical RES content;
- that non-user automation must invent a user profile;
- that `NOT_APPLICABLE_WITH_BASIS` may be used without evidence;
- that this package upgrades any already-running server process without reload/readback;
- that source publication itself establishes doctrine activation;
- that parent v1.1 qualification is independently re-authored here.

`UCM != PROJECT_AUTHORITY`
